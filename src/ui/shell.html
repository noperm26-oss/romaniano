WEBGL INITIALIZATION FAILED

The battlefield cannot be rendered. This game needs WebGL — a graphics system built into modern browsers.

Possible causes:
• Hardware acceleration is disabled in your browser settings
• Your browser is outdated (Chrome 90+, Edge 90+, Firefox 90+ recommended)
• Your GPU driver is outdated or blocked
• You opened the file with a very old viewer

Try:
• Reload the page
• Enable hardware acceleration: Chrome → Settings → System → Use hardware acceleration
• Update your browser & GPU driver
• Try a different browser (Chrome, Edge, Firefox)

Check WebGL Browser Requirements

If WebGL is supported, the game runs fully offline — your machine is the server. No install needed.
